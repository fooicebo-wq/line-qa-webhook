隱私權政策

本隱私權政策說明「集思室內設計」（以下稱「本公司」）在使用 Pinterest API 自動發佈內容之應用程式（以下稱「本應用程式」）時，如何處理相關資料。

一、本應用程式的用途

本應用程式僅用於將本公司自有的室內設計案例（照片與文字說明）發佈為 Pin，至本公司自己的 Pinterest 商業帳號，並導流回本公司官方網站，作為內容行銷用途。本應用程式透過 Pinterest API 建立 Pin 及讀取本公司自有的 Board 資訊，僅發佈本公司自有內容。

二、我們蒐集與使用的資料

  • 本應用程式不蒐集、不儲存任何第三方或一般使用者的個人資料。
  • 本應用程式僅使用本公司授權之 Pinterest 帳號存取權杖（access token），用以發佈本公司自有內容；該權杖安全保存於本公司後端伺服器的加密環境變數中，不對外公開。
  • 本應用程式不追蹤使用者行為、不使用 Cookie 蒐集個資。

三、資料分享

本公司不會出售、出租或與任何第三方分享透過本應用程式取得的任何資料。

四、資料安全

Pinterest 存取權杖以加密環境變數方式保存於受保護的伺服器環境，僅供本應用程式發佈本公司內容之用。

五、撤銷授權

本公司可隨時於 Pinterest 帳號設定中撤銷本應用程式的存取權限；撤銷後本應用程式將無法再存取該帳號。
